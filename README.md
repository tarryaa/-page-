# 日本史索引（iPhone用アプリ）

日本史教科書の索引を検索するアプリです。
HTML・CSS・JavaScript だけで動きます。外部のライブラリやCDNは使っていません。
サーバーやビルド作業も不要です。

---

## 0. ファイルの一覧

```
index.html        アプリの本体（この1枚が画面）
style.css         見た目
app.js            画面の動き・データの読み込み・絞り込み
search.js         検索の頭脳（正規化・ルビ解析・検索判定）
sw.js             オフラインで使えるようにする係
manifest.json     ホーム画面に追加したときの名前やアイコンの設定
icons/            アイコン3枚（180 / 192 / 512）
data/             索引データ（CSV 4つ）
test.html         動作テスト（開くと結果が表示されます）
make-icons.html   アイコンを作り直したいときだけ使うおまけ
README.md         この説明書
```

`data/` の中身は、お渡しいただいた4つのCSVをそのままコピーしたものです。

## 1. パソコンで動作を確認する

### いちばん簡単な方法（ダブルクリック）

1. `index.html` をダブルクリックします。
2. **「データがまだありません」という画面が出ます。** これで正常です。
   （※ 理由：パソコンでファイルを直接開いたときは、ブラウザの安全上の決まりで、
   同じフォルダのCSVを自動で読み込むことが禁止されています。
   インターネットに公開したあと（GitHub Pages）は、この制限はなくなり自動で読み込まれます）
3. 「データを取り込む」ボタンを押します。
4. ファイルを選ぶ画面で、`data` フォルダを開き、**4つのCSVをまとめて選びます**。
   （1つ目をクリック → キーボードの Shift を押しながら4つ目をクリック → 「開く」）
5. すぐに一覧が出ます。検索・絞り込み・並び替えが全部そのまま試せます。

この方法でも、アプリの機能はすべて確認できます。

### 検索テストを見る

1. `test.html` をダブルクリックします。
2. 「CSVを選ぶ」ボタンが出たら押して、`data` フォルダの `nihonshi_index_all.csv` を選びます。
3. テストの合格・不合格が表の形で出ます。**全部「○ 合格」になっていればOK**です。
   下に検索の速さも出ます（目標は50ミリ秒以内）。

## 2. GitHub にアップロードして公開する

### アップロードするもの

| 種類 | 名前 |
|---|---|
| ファイル | `index.html` |
| ファイル | `style.css` |
| ファイル | `app.js` |
| ファイル | `search.js` |
| ファイル | `sw.js` |
| ファイル | `manifest.json` |
| ファイル | `test.html` |
| ファイル | `make-icons.html`（無くても動きます） |
| ファイル | `README.md`（無くても動きます） |
| **フォルダ** | `icons`（中のPNG3枚ごと） |
| **フォルダ** | `data`（中のCSV4つごと） |

※ `claude_code_prompt.md` と、フォルダの一番上にある4つのCSV（`data` の外にあるもの）は
アップロードしなくて大丈夫です。

### 手順

1. GitHub で **Public** のリポジトリを新しく作ります。
2. リポジトリの画面で「Add file」→「Upload files」を押します。
3. エクスプローラーで上の表のファイルを選び、**アップロード画面にドラッグ＆ドロップ**します。
4. **フォルダをアップロードするときの注意点**
   - `icons` と `data` は、**フォルダごと**ドラッグ＆ドロップしてください。
     （フォルダを開いて中身だけを入れると、`data/～` という場所ではなくなり、
     アプリがデータを見つけられません）
   - ドラッグ＆ドロップならフォルダのまま上がります。
     画面の「choose your files」リンクから選ぶ方法では、フォルダは選べません。
   - アップロード後、一覧に `data` と `icons` が**フォルダの形**で表示されていることを
     確認してください。
5. 下の「Commit changes」を押します。
6. リポジトリの「Settings」→ 左メニューの「Pages」を開きます。
7. 「Branch」を **main**、フォルダを **/(root)** にして「Save」を押します。
8. 1〜2分待つと、Pages の画面に公開アドレスが出ます。
   `https://（あなたのユーザー名）.github.io/（リポジトリ名）/` という形です。

## 3. iPhone のホーム画面に追加する

1. iPhone の **Safari** で、上の公開アドレスを開きます。
   （Chrome など他のブラウザではなく、必ず Safari を使ってください）
2. 一覧が出たら、画面の下にある **共有ボタン**（四角から上向きの矢印が出ているマーク）を押します。
3. メニューを下にスクロールして「**ホーム画面に追加**」を押します。
4. 名前が「日本史索引」になっていることを確認して、右上の「追加」を押します。
5. ホーム画面に「史」のアイコンができます。これを押すと、アドレスバーの無い
   アプリのような画面で開きます。
6. **一度開いておけば、機内モードでも使えます。**
   （初回だけは電波かWi-Fiが必要です。データを読み込んで端末に保存します）

## 4. データを直したあと、アプリに反映させる

索引CSVを直したときは、次の順番で作業してください。

1. パソコンで `data` フォルダの中のCSVを新しいものに置き換えます。
2. **`sw.js` をメモ帳などで開き、5行目あたりにある次の行を探します。**

   ```js
   var CACHE_VERSION = 'v1';
   ```

3. **`'v1'` の数字を1つ増やします。**（`'v2'` → 次は `'v3'` → その次は `'v4'` …）
   ここを変えるのを忘れると、iPhoneが古いデータを覚えたままになります。
   変えれば、古いものは自動で消えて新しい内容に入れ替わります。
4. GitHub で「Add file」→「Upload files」を開き、
   **`data` フォルダ**と**`sw.js`** をドラッグ＆ドロップして「Commit changes」を押します。
   （同じ名前のものは自動で上書きされます）
5. iPhone でアプリを一度閉じて、開き直します。1〜2回開き直すと新しくなります。
6. それでも変わらないときは、アプリの右上「設定」→「**最新版を読み込み直す**」を押してください。

※ アプリのファイル（`index.html` や `app.js` など）を直したときも、同じように
`CACHE_VERSION` の数字を1つ増やしてください。

## 5. manual_tags.csv に重要語の時期を書き足す

索引データの「年」だけでは、時期の絞り込みに出てこない語があります。
そういう重要語を、手で時期に結びつけるための表です。

### 書き方

- `data/manual_tags.csv` をメモ帳などで開きます。
- 1行目の `用語,時期ID` はそのままにして、2行目から書き足します。
- **1行に1つ**です。同じ用語を2つの時期に付けたいときは、2行に分けて書きます。
- 「用語」は、索引データの「用語」と**一字一句そのまま**にしてください。
- 「時期ID」は `data/periods.csv` の**一番左の列**の文字です。

### 書き方の例（3つ）

```
用語,時期ID
鉄砲,edo_p04
刀狩令,azuchi_02
徳川吉宗,edo_p04
```

- 1つ目：「鉄砲」を **享保の改革**（ID: `edo_p04`）の語としても出す
- 2つ目：「刀狩令」を **豊臣政権**（ID: `azuchi_02`）の語としても出す
- 3つ目：「徳川吉宗」を **享保の改革** の語としても出す

同じ用語を2つの時期に付けたいときは、こう書きます。

```
用語,時期ID
鉄砲,azuchi_01
鉄砲,edo_p04
```

### よく使う時期IDの見つけ方

`data/periods.csv` を開くと、左から
「ID・親ID・区分名・開始年・終了年・備考」の順に並んでいます。
たとえば `edo_p04,edo_p,享保の改革,1716,1745,` という行なら、IDは `edo_p04` です。

書き足したら、**第4章の手順**（`sw.js` の数字を増やしてアップロード）で反映させてください。

## 6. データを同梱する場合／しない場合

リポジトリが Public なので、`data` フォルダを一緒にアップロードすると、
索引データは誰でも見られる状態になります。どちらでも動くように作ってあります。

### A. 同梱する場合（おすすめ・今の状態）

- **手順**：`data` フォルダを一緒にアップロードするだけです。
- **使い心地**：iPhone で開くとすぐに一覧が出ます。何もしなくて構いません。
- **注意**：索引データがインターネット上で公開されます。

### B. 同梱しない場合

- **手順**：アップロードするとき、**`data` フォルダだけ外します**。
  （すでに上げてしまった場合は、GitHub 上で `data` フォルダを開き、
  ファイルごとに「…」→「Delete file」で消します）
- **使い心地**：iPhone で最初に開くと「データがまだありません」の画面が出ます。
  1. あらかじめ、4つのCSVを iPhone の「ファイル」アプリに入れておきます
     （iCloud Drive に入れる、メールで自分宛てに送って保存する、などの方法があります）。
  2. アプリの「データを取り込む」を押し、「ファイル」アプリから4つをまとめて選びます。
  3. 取り込んだデータは iPhone の中に保存されるので、**次からは自動で読み込まれます**。
- **注意**：`sw.js` の `ASSETS` に `data/...` の行が残っていても、
  ファイルが無いだけなので問題ありません（自動で読み飛ばします）。
- **データを直したとき**：iPhone で「設定」→「データを取り込む」からもう一度取り込みます。

※ 同梱データと取り込んだデータの両方があるときは、**取り込んだデータが優先**されます。
元に戻したいときは「設定」→「取り込んだデータを削除」を押してください。

## 7. 検索の使い方（アプリ内の「設定」にも書いてあります）

| 入力 | 意味 |
|---|---|
| `日中平和` | 漢字で部分一致 |
| `にっちゅうへいわ` | 読みで部分一致 |
| `日中へいわ` | 漢字と読みを混ぜてもOK |
| `ほうじょう ときむね` | 空白で区切ると「両方を含む」（AND） |
| `日中〜` | 「日中」で始まる語 |
| `〜条約` | 「条約」で終わる語 |
| `日〜条約` | 「日」で始まり「条約」で終わる語 |
| `日中〜 〜条約` | 組み合わせもできます |

- `〜` は、iPhone で「から」と入力して変換すると出ます。
  全角「～」・半角「~」でも同じように使えます。
- 全角と半角、大文字と小文字、カタカナとひらがなは区別しません。
  （`ｇａｔｔ` でも `gatt` でも GATT が出ます）
- メモ欄の別名でも探せます。`天草四郎` で「益田時貞」が出て、「別名：天草四郎時貞」と表示されます。

## 8. 困ったときは

| 症状 | 対処 |
|---|---|
| ホーム画面のアイコンが白い | GitHub に `icons` フォルダごと上がっているか確認 → 一度削除して追加し直す |
| データを直したのに変わらない | `sw.js` の `CACHE_VERSION` の数字を増やして上げ直す → 「設定」→「最新版を読み込み直す」 |
| 一覧が出ない（公開後） | `data` フォルダがフォルダの形で上がっているか確認する |
| 一覧が出ない（パソコン） | 正常です。第1章の手順で「データを取り込む」を使ってください |
| アイコンを作り直したい | `make-icons.html` を開いて「3つまとめて保存」→ `icons` フォルダに上書き |
